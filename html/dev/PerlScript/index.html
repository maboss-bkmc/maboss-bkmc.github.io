PlMaBoSS_3.0.pl
MaBoSS should be installed and available through a command line.
Running perl script: "PlMaBoSS_3.0.pl file.bnd file.cfg (optional)threshold (optional)-mb MaBoSS_executable_name"
This will create a directory, with the same name as the cfg file (adding a number if directory already exists).
The directory contains input files and output files. It also contains csv-processed files (file_cfg_probtraj_table.csv and file_cfg_statdist_table.cfg (if the threhold is given). The threshold is used in the file "file_cfg_statdist_table.cfg", in order to suppress states whose probability is below the threshold.
